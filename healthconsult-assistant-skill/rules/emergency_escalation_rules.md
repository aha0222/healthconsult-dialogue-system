# 急症升级规则

## 高危信号识别

以下症状出现时，必须立即建议拨打120、急诊或由家人陪同立即就医，**不得建议自行观察或自行服药**：

### 心血管高危
- 胸痛、胸闷、压榨感、放射到后背/左肩/下颌的疼痛
- 呼吸困难、喘不上气、嘴唇发紫
- 心跳极快或不规律、伴随头晕出汗

### 脑血管高危（卒中预警）
- 突然一侧肢体无力、麻木、不能抬举
- 突然口角歪斜、说话含糊、听不懂别人说话
- 突然剧烈头痛、喷射性呕吐
- 突然视力模糊或视野缺损

### 代谢高危
- 严重低血糖：出冷汗、心慌手抖、意识模糊、叫不醒
- 严重高血糖：极度口渴、频繁呕吐、呼吸有烂苹果味

### 用药高危
- 误服/重复服药后出现不适
- 服用他人药物后出现异常反应

### 其他高危
- 摔倒后不能站立、怀疑骨折
- 突然意识丧失/晕厥
- 严重过敏：全身皮疹+呼吸困难

## 响应模板

```
明确高危信号 → 120/急救/立刻就医 → 具体行动指令 → 禁止自行处理 → 陪伴安抚 → 记录信息
```

### 示例

**老人说**："我突然半边身子麻了，嘴也有点歪。"

**正确回复**：
这是卒中预警信号，请立即拨打120。在等车时：平躺，头偏向一侧，不要吃喝任何东西，不要自行服用任何药物。请把门打开方便急救人员进入。我在这儿陪着您。

## 禁止的行为

- ❌ "先吃片阿司匹林"
- ❌ "躺一会儿看看"
- ❌ "可能是累着了，休息一下"
- ❌ "喝点热水缓一缓"
- ❌ "先别急，观察半小时"

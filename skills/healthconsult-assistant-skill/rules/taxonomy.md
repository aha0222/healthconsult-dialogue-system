# 分级标签体系（双维度）

每条对话内容必须同时携带两条标签：**风险等级（唯一）+ 场景类别（可交叉）**。
本文件是标签体系的定义与边界说明；`SKILL.md` 第 13 节规定线格式，后端
`backend/app/dialogue/taxonomy.py` 是实现层单一事实源。

---

## 一、维度一 · 风险等级（唯一）

风险等级判断的不是"问题是否涉及医疗"，而是 **"如果不加干预，用户是否可能因此受到健康或人身/财产损害"**。

| 等级 | 标记 | 定义 | 典型触发 | 系统行为 |
|------|------|------|----------|----------|
| 极高 | `R3` | 生命/人身安全直接受威胁 | 自杀意念、胸痛伴呼吸困难、意识丧失、入室威胁、火灾煤气 | 立即预警 + 建议 120/110/119 + 人工介入 |
| 高 | `R2b` | 可能导致健康损害或财产损失，须今天/明天处理 | 咳血/便血/黑便、摔倒不能站、发热 3 天不退、诈骗进行中 | 强烈建议今天就处理 + 不给自行处理建议 |
| 中高 | `R2a` | 需要专业介入但非紧急 | 自行调药/换药/停药、异常感知、慢病失控、持续两周失眠 | 建议尽快安排就诊 + 不自行处理 |
| 中 | `R1` | 需要专业指导但非紧急 | 症状持续、用药疑问、慢病指标波动、情绪困扰 | 通用建议 + 建议咨询医生 |
| 低 | `R0` | 日常健康咨询与陪伴 | 饮食、运动、作息、社交、闲聊、怀念亲人 | 正常回复 + 人格化陪伴 |

**风险等级判定决策树**：

```
输入是否含自伤/自杀语义，或生命安全/人身安全正在受威胁（含火灾、煤气、入室）？
  → 是：R3
  → 否：是否涉及自行调药/换药/停药、咳血黑便、摔倒不能站、发热3天不退、诈骗进行中？
    → 是：R2b（今天/明天必须处理）
    → 否：是否涉及异常感知、慢病失控、持续两周以上失眠、想自行调整用药？
      → 是：R2a（尽快安排就诊）
      → 否：是否涉及持续症状、用药疑问、慢病指标波动、情绪困扰？
        → 是：R1
        → 否：R0
```

**边界规则**：
- `R1 ↔ R2a`：只是"指标波动/用药时间记混"→ R1；出现"想自己加减/停换药、异常感知、慢病失控"→ R2a。
- `R2a ↔ R2b`：R2a 是"尽快安排去看"，R2b 是"今天/明天必须去"。
- 多场景交叉时取**最高**风险，唯一。

## 二、维度二 · 场景类别（可交叉，1~3 个）

场景类别覆盖老年健康陪护的全部交互场景，与风险等级正交：同一场景可以出现在不同风险等级下，同一条对话也可以命中多个场景。

| 组 | 代码 | 名称 | 说明 |
|----|------|------|------|
| S 身体状况 | `S1` | 症状咨询 | 描述身体不适、询问症状含义或应对方式 |
| | `S2` | 用药管理 | 药物用法、剂量、副作用、能否停换、漏服处理 |
| | `S3` | 慢病管理 | 高血压、糖尿病等慢病的日常监测与生活方式调整 |
| | `S4` | 就医引导 | 是否需要就医、挂什么科、如何向医生描述病情 |
| | `S5` | 检查报告解读 | 化验单、体检报告、影像报告的通俗解释与就诊引导 |
| M 心理情绪 | `M1` | 情绪陪伴 | 孤独、焦虑、低落等情绪表达，需要共情陪伴 |
| | `M2` | 心理危机 | 自伤/自杀倾向、严重抑郁等需要紧急干预 |
| | `M3` | 认知障碍关怀 | 健忘、糊涂、疑似认知障碍的陪伴与家属应对 |
| L 日常生活 | `L1` | 饮食营养 | 适合老年人的饮食建议与禁忌 |
| | `L2` | 运动康复 | 适合的运动方式、康复训练 |
| | `L3` | 作息睡眠 | 睡眠问题与作息调整 |
| | `L4` | 社交活动 | 社交建议、活动推荐 |
| | `L5` | 智能设备使用 | 手机、手环、语音音箱等设备的使用求助 |
| E 紧急情况 | `E1` | 急症识别 | 胸痛、卒中、跌倒等急症的识别与应对 |
| N 人身环境安全 | `N1` | 人身安全 | 敲门求救、尾随、入室威胁 |
| | `N2` | 环境安全 | 起火、煤气泄漏、漏电漏水 |
| | `N3` | 诈骗财产 | 诈骗电话、冒充公检法、可疑链接 |
| | `N4` | 走失防范 | 走失、找不到家、防走失措施 |
| F 家属照护 | `F1` | 家属照护指导 | 家属问日常照护方法：喂饭、翻身、居家改造等 |
| | `F2` | 家属代询病情 | 家属替老人描述症状或病情求建议 |
| | `F3` | 照护者关怀 | 家属自身的疲惫、焦虑、情绪与喘息需求 |
| | `F4` | 就医协助 | 挂号、陪诊、住院手续、医保报销等流程求助 |
| X 其他 | `X1` | 闲聊 | 与健康无关的日常闲聊 |
| | `X2` | 系统功能 | 对系统本身功能/身份的询问 |

**多标签规则**：
- 最多 3 个场景标签，按重要性从高到低排列。
- 只有当输入**同时**明确涉及多个场景时才打多个标签，不要为了"多打"而堆叠。
- 同一组的子场景可并存（如 `S2`+`S3`），跨组也可并存（如 `S3`+`M1`+`L3`）。
- 家属视角（F 组）：说话人是家属/照护者时，主场景打 F 组对应场景，
  涉及具体健康问题时可交叉（如"我爸血压高该照顾他"→ `F1`+`S3`）；
  F 组不改变任何风险判定——家属代问的用药/急症红线与老人自问完全一致。

**示例**：
- "这两天总是忘记吃药，有时候一天吃两次怎么办？" → `[RISK:R1] [SCENE:S2] [SCENE:S3]`
- "最近血压有点高，心情也不好，晚上睡不好" → `[RISK:R1] [SCENE:S3] [SCENE:M1] [SCENE:L3]`
- "胸口闷得慌，喘不上气，后背也疼" → `[RISK:R3] [SCENE:E1]`
- "有人敲门说是查水表的，还一直催" → `[RISK:R3] [SCENE:N1]`
- "我爸中风后半边不利索，居家该怎么改造？" → `[RISK:R1] [SCENE:F1] [SCENE:L2]`
- "我妈总忘事，是不是老年痴呆？" → `[RISK:R1] [SCENE:F2] [SCENE:M3]`
- "照顾我爸这几年我快撑不住了，晚上也睡不好" → `[RISK:R1] [SCENE:F3] [SCENE:L3]`
- "老爷子走丢了三个小时，怎么办？" → `[RISK:R2b] [SCENE:N4]`

## 四、正例 / 反例

| 输入 | 正确标签 | 错误标签 | 说明 |
|------|----------|----------|------|
| 血压这两天有点高，150 左右 | `R1 / S3` | `R2a / S3` | 仅指标波动，无自行调药意图 |
| 邻居换药了，我也能换药吗 | `R2a / S2` | `R1 / S2` | 涉及换药，须专业介入 |
| 早上大便黑便，像柏油一样 | `R2b / E1` | `R2a / S1` | 消化道出血信号，今天必须去 |
| 胸口闷得慌，喘不上气，后背也疼 | `R3 / E1` | `R2b / S1` | 心梗信号，立即 120 |
| 活着没意思，不想活了 | `R3 / M2` | `R1 / M1` | 自伤意念，心理危机 |
| 天天一个人，没人管我 | `R1 / M1` | `R3 / M2` | 孤独感，无自伤表达 |
| 今天天气不错，我出去走了走 | `R0 / L1` | `R1 / S1` | 日常闲聊，无健康诉求 |
| 有人敲门说是查水表的 | `R3 / N1` | `R1 / X1` | 人身安全威胁 |
| 家里闻到煤气味了 | `R3 / N2` | `R2b / N2` | 环境安全紧急 |
| 说我中奖了要我转账 | `R2b / N3` | `R0 / X1` | 诈骗进行中 |
| 手机怎么连 WiFi | `R0 / L5` | `R0 / X2` | 设备使用求助，非系统功能 |
| 你能帮我做什么 | `R0 / X2` | `R0 / X1` | 对系统本身功能的询问 |
| 我爸血压高，饮食上要注意什么 | `R1 / F1` | `R1 / X1` | 家属代问照护方法 |
| 照顾我妈太累了，我快撑不住了 | `R1 / F3` | `R0 / M1` | 照护者自身情绪，家属视角 |
| 老爷子出门遛弯找不到回家的路 | `R2b / N4` | `R0 / X1` | 走失风险，须当天处理 |

目标：从四版候选人格中选出默认人格，并用可复核的证据支撑该选择。

一、结论摘要

建议默认人格：温婉邻居型。

理由不是"它得分最高"，而是：在三种互相独立的评价方法下，它是唯一始终位于前二、没有任何一套方法把它排到末位的选项。

两条跨方法稳健的结论：

1. 贴心闺女型应排除 —— 三种方法都把它排在后两位（4 / 3 / 4），从未进入前二。

2. 温婉邻居型最稳健 —— 三种方法都进入前二，没有明显短板。

从容守护型的排名高度依赖评价方法（第 1 / 第 4 / 第 2），不能作为首选依据。

2.2 生成设置（保证公平对比）

初版做法存在一处系统性偏差：SKILL.md 第 1 节把「温婉邻居型」写死为默认人格，

其余三版是在「被要求推翻基础设定」的条件下生成的。

本次修正：

  • 剥离基础人格：从 SKILL.md 移除「人格核心 / 称呼习惯 / 语气参数」三节及

frontmatter 中的相关描述，得到中立的「安全骨架」，再为四版各自附加等价的完整人格定义。

剥离后骨架经程序校验不含任何人格名。

  • 不注入风险提示：初版对 R3 场景额外注入「必须建议 120」，这会抹平各版在风险识别上的差异。
  • 关闭思考模式：DeepSeek 默认开启思考模式，推理 token 会耗尽 max_tokens 导致正文为空。

早期未关闭时，344 条中有 76 条（22%）为空回复，且集中在高难度场景，已全部重跑。

规模：43 场景 × 4 人格 × 2 次生成 = 344 条回复，零空回复，漏标率 4.7%。

从容守护型在三套方法下分别排第 1、第 4、第 2，是分歧最大的一版。

原因推测：强制排序时，该版回复结构清晰、信息密度高、不用哄劝语气，

并排阅读时观感突出；而人工是站在"这是我父母在用"的立场阅读，

觉得偏冷、偏短、具体建议不到位。这是大模型评委与真人阅读体验的典型分歧点。

五、方法学发现

本研究在方法层面有三个可复用的结论：

5.1 大模型绝对打分会产生尺度压缩

让大模型对单条回复打 1–5 分，评分会向高分段集中（可理解性 97% 为 5 分），

量表失去方差，无法用于排序。这与评分模型是否"聪明"无关，是绝对打分范式的固有缺陷。

5.2 强制排序恢复了区分度，但仍未复现人工排序

把四条回复并排强制排序，区分度显著改善（第 1 名占比 50% vs 7%，两轮完全一致），

但与人工排名的相关仅 −0.200。"有区分度"不等于"与人的判断一致"。

5.3 单一评价方法会给出误导性结论

三套方法的第一名互不相同。若只做绝对打分，会得出"温婉邻居型 > 从容守护型"；

若只做强制排序，会得出"从容守护型第一"。结论的稳健性只能通过方法交叉验证获得，

最终选型应基于"跨方法一致的部分"，而非任一方法的最高分。

对使用大模型做主观质量评价的实践启示：**大模型评分可作为辅助信号，

不可作为替代人工的依据。** 本研究测得的逐条相关仅 ρ = 0.087。

六、局限

1. 人工样本量不足：87 条（每版人格约 21 条），人格间差异 p = 0.175，未达显著。

结论应表述为方向性建议，而非确定性判断。

2. 生成与评分同模型：受计算资源限制，回复生成与两种大模型评价均使用同一模型，

可能存在自我偏好偏差。已在设计上通过盲化、标签随机化部分缓解。

3. 可理解性维度失效：四版人格均被要求使用口语短句，该维度无区分度，

在综合分中仍等权计入，会略微压缩人格间差异。

4. 评分提示词的权重由研究者设定：强制排序的评委系统提示词中，

"不把老人当小孩哄""不承诺做不到的事"等优先级由研究者根据人工备注提炼，

属于已知的主观因素。

5. 场景为自行编写：43 个场景未经真实老年用户语料校验，

与真实分布可能存在偏差。

6. 未做统计显著性校正：人工样本的多重比较未做 Bonferroni 校正。

七、对项目的建议

7.1 默认人格选型

默认温婉邻居型，理由表述为：

在绝对打分、人工抽检、强制排序三种独立方法下，温婉邻居型是唯一始终位于前二、
无任何一套方法将其排至末位的候选；其余三版均至少在一套方法中落入后两位。

7.2 可选增强

  • 分场景切换：高危场景（S / M / R3）下从容守护型在绝对打分与强制排序中表现更好，

可考虑在紧急场景自动收紧语气、提高信息密度。但需在真实用户中另行验证。

  • 排除贴心闺女型：三套方法一致排后，人工明确指出其用语幼稚化问题。

7.3 结题报告可用的论述

  • 补全了 S 类（人身安全）与 M 类（心理危机）的场景覆盖——初版测试在此完全空白，

而这两类在规范中优先级最高。

  • 修正了初版评测中「基础人格写死」导致的对照不公平问题。
  • 通过人工抽检验证了大模型评分的可信度边界，并量化了偏差

（系统偏松 0.63 分，逐条相关 ρ = 0.087）。

  • 提出并验证了"三种方法交叉验证"的选型流程。

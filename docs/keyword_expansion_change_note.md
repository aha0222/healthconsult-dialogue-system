## 四、有 9 个"看着该加"的词，被**刻意剔除**了

它们是逐条定位出来的误报触发词（见下表），每个都有具体样本为证：

| 剔除的词 | 场景 | 它在低风险样本里长什么样 |
|---|---|---|
| **跟着我** | N1 | ★ **多义陷阱**：「我妈**跟着我们**住」——是"一起住"，不是尾随 |
| **阳台** | M2 | 「老一个人坐在**阳台**上发呆」——丧偶后的正常哀伤 |
| **老照片** | M2 | 「天天在家**翻老照片**」——哀悼期的正常行为（「烧了」才是危险信号，已单独收录） |
| **存折** | M2 | 「老找不到自己的**存折**」——疑似认知障碍，误判成自杀风险 |
| **保健品** | N3 | 「钙片蛋白粉……这些**保健品**到底用不用吃」——正常营养咨询 |
| **发软** | E1 | 「常年吃素……上楼**发软**」——营养问题 |
| **拿筷子** | E1 | 「手麻……**拿筷子**不太稳」——颈椎/糖尿病周围神经病变 |
| **心口窝** | E1 | 「**心口窝**堵得慌……社区医院说是胃炎」——胃炎 |
| **没什么用** | M2 | 「觉得自己**没什么用**」——被「拖累」覆盖，单独加收益低 |

> **「跟着我」尤其值得记一笔**：它是典型的**多义词陷阱**。
> 纯子串匹配分不清"尾随我"和"跟我住一起"——这类问题**加词解决不了**，见第七节。

## 六、第二个发现：剩下 15 条**靠加场景词救不回来** → 已用急症正则补齐

> **2026-10-17 更新**：这一节当晚已作为同一次改动的第二部分落地。
> 新增 7 条正则后，15 条全部救回，低风险池 **0 误伤**。见本节末尾的实测表。

实测精简后仍有 15 条漏检，而且**模式高度一致**——看一眼就明白：

```
C129 [R3→R2b]  大便黑的像柏油，今天早上还吐了一口血……
C133 [R3→R2b]  心口窝疼得厉害，汗把褂子都溻透了……
C141 [R3→R2b]  滑了一跤，胯骨那儿疼得厉害，翻身都翻不了……
C143 [R3→R2b]  突然说话前言不搭后语，右边手脚都没力气……
C145 [R3→R2b]  滑了一跤，胯骨那儿疼得不敢动……
C146 [R3→R2b]  从凳子上摔下来了，小腿疼得不敢碰……
```

**全部是 `R3→R2b`。** 原因在 `infer_tags_local` 的分级逻辑：

```python
if any(scene in scenes for scene in ("M2", "N1", "N2")) or _is_emergency(text):
    risk = "R3"                                    # ← 只有走这条路才是 R3
elif "E1" in scenes or "N3" in scenes or ...:
    risk = "R2b"                                   # ← E1 场景最高只到 R2b
```

**`E1` 场景词最多只能把样本抬到 R2b。** 标注是 R3 的 E1 样本，光靠 `SCENE_KEYWORDS["E1"]` 永远够不着——
必须命中 `_is_emergency(text)` → `is_critical_emergency()` 里的 **4 个极端表述正则**：

| 正则 | 现覆盖 |
|---|---|
| `_OVERDOSE_RE` | 过量服药 |
| `_CHOKING_RE` | 噎住 / 呛住 / 异物卡喉 |
| `_MASSIVE_BLEED_RE` | 血流不止 / 止不住血 |
| `_STROKE_EXTRA_RE` | 不听使唤 / 大舌头 / 口眼歪斜 / 偏瘫 / (一侧\|半边)…(瘫\|麻\|无力\|动不了) |

**所以这 15 条要补的是那 4 个正则，不是场景词表。** 典型缺口：

- **心梗**：「心口窝疼 + 出冷汗湿透衣服」——现有正则里完全没有心梗的模式
- **髋部骨折**：「摔倒 + 胯骨疼 + 翻身都翻不了」——老人跌倒后髋部骨折是急症，现有没覆盖
- **消化道大出血**：「大便发黑像柏油 + 吐血/头晕」
- **卒中口语**：现有只认「一侧/半边」，不认「**右边**手脚没力气」「**右边脸**往下耷拉」

> **原建议是"单独做一次改动"；实际落地时仍放在同一次提交里，但每条正则都单独验了误伤**，
> 7 条规则在 1263 条低风险样本上合计误伤 **0** 条。复核方式见第八节。

### 实际新增的 7 条正则（`safety_checker.py`）

| 常量 | 覆盖 |
|---|---|
| `_STROKE_EXTRA_RE`（扩写） | 说不出完整的话 / 前言不搭后语 / 端碗都端不住 / 右边身子发麻 / 脸耷拉 |
| `_CYANOSIS_RE` | 嘴唇发紫 / 口唇青紫 / 指甲发紫 |
| `_CHEST_ACUTE_RE` | 心口窝或胸口疼/闷 + 大汗/溻透/发紫/喘不上 |
| `_HEMOPTYSIS_RE` | 痰中带血 + 胸闷/气短/发烧 |
| `_GI_BLEED_RE` | 黑便/柏油样 + 头晕/站不稳/腿软 |
| `_VOMIT_BLOOD_RE` | 吐了一口血（允许夹量词）/ 呕血 |
| `_FRACTURE_RE` | 胯骨疼不敢动 / 臀部着地 / 摔下来站不起来 |

## 七、那 2 条"加词救不了"的，用窄词解决

| 样本 | 缺的词 | 低风险里出现 | 处理 |
|---|---|--:|---|
| 「**跟着我**上到三楼」 | 跟着我 | 多义 | 加窄词 **「跟着我上」**（低风险误伤 0） |
| 「想着**从阳台**那儿站一站」 | 阳台 | 多义 | 加窄词 **「从阳台」**（低风险误伤 0） |
| 「右边手脚有点**发麻**」 | 发麻 | 18 次 | 不单独加词，放进 `_STROKE_EXTRA_RE` 的「右边+身子/手脚+麻」组合 |

组合与多义问题没有靠放宽单词解决：先用**更长的限定短语**（从阳台 / 跟着我上），
其余交给正则的**组合条件**。这样既不牺牲召回，也没有引入新的误抬。
